QUICK START

Python, not framework ceremony.

Declare what you need and let PyAPIfy handle the infrastructure.

from pyapify import PyAPIfy

api = PyAPIfy()

@api.get("/hello")
def hello():
    return {"message": "Hello!"}

api.run()
PLUGIN ECOSYSTEM

Extend PyAPIfy. Nothing else.

Plugins are first-class PyAPIfy extensions. Browse the registry, download an extension, place it in .pyapify/plugins/, and use it in your application.

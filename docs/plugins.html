PLUGIN REGISTRY

Extend PyAPIfy.

This registry is for extensions that add capabilities to PyAPIfy. Plugins do not exist to extend Python itself.

No plugin manager required.
Download an extension, place its folder in .pyapify/plugins/, then load it through PyAPIfy.

Install guide

Installation

.pyapify/
└── plugins/
    └── example_plugin/
        ├── main.py
        ├── info.json
        └── src/
            ├── __init__.py
            └── ...
# main.py
from pyapify import Plugin

plugin = Plugin()
example = plugin.load("src/__init__.py")

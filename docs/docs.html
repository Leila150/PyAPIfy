PyAPIfy Docs

The framework is built around one idea: declare information once and keep the common path simple.

Quick start

from pyapify import PyAPIfy

api = PyAPIfy()

@api.get("/users/{id:int}")
def user(id: int):
    return {"id": id}

api.run()

Core features

RoutingTyped paths, HTTP methods, groups and named routes.
RequestsQuery, headers, cookies, forms, files and JSON bodies.
ModelsTyped models, validation, serialization and schemas.
InfrastructureMiddleware, dependencies, authentication, lifecycle and background tasks.
RealtimeWebSockets and Server-Sent Events.
TestingIn-process test client without starting a real server.
PluginsOfficial extension API for adding PyAPIfy capabilities.

Plugins

A plugin is a PyAPIfy extension, not a general-purpose Python plugin. Extensions can add decorators, functions, hooks, route types, middleware, CLI commands, configuration, tests and custom run systems.

from pyapify import Plugin

plugin = Plugin()

@plugin.create_decorator(name="cache")
def cache(api, *args, **kwargs):
    def decorator(fn):
        return fn
    return decorator

Install a plugin by placing its directory under .pyapify/plugins/.
